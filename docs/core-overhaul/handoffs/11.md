## Contract and API examples

The engine remains the frozen `RunAnalysisV2`:

```ts
const result = await createRunAnalysisV2({
  attempt: lease.attempt,
  fencingToken: lease.fencingToken,
  reuse: ownerScopedExactLookup,
})(payload.analysis, environment);
```

The HTTP adapter returns durable identity instead of waiting on a detached promise:

```json
{
  "schemaVersion": 2,
  "engineVersion": "core-v2.0.0",
  "runId": "<uuid>",
  "status": "queued",
  "progressUrl": "/api/tracera/v2/runs/<uuid>",
  "eventsUrl": "/api/tracera/v2/runs/<uuid>/events",
  "cancelUrl": "/api/tracera/v2/runs/<uuid>/cancel",
  "reportUrl": "/run/<uuid>"
}
```

`GET /v2/runs/:id` and `/events` return persisted job progress and the report only after terminal
job completion. `POST /cancel` is the only browser action that requests cancellation. Evidence
links are scoped as `/v2/runs/:runId/evidence/:snapshotId?start=N&end=M`; invalid offsets or a
snapshot absent from that run's report are rejected.

## Security, isolation, cancellation, spend, and audit

Every database operation added here carries tenant, owner, and visibility scope except global job
lease selection, which returns the stored scope and frozen run context to the worker. All subsequent
checkpoint, snapshot, cancellation, progress, report, and evidence operations reapply that scope.
Public visibility is never inferred as publication consent; v2 submissions are private. Other
owners receive 404 for run/evidence existence and cannot cancel.

Browser/SSE disconnect does not alter durable state. Explicit cancellation marks queued jobs
terminal immediately or is polled by the active worker; the worker aborts stage work, acknowledges
with the current attempt and fencing token, settles held provider reservations, and stores no
canceled scorecard. Graceful process shutdown is distinct: it returns the lease to retry instead of
misreporting user cancellation. Expired and stale workers cannot checkpoint, acknowledge, retry, or
finalize.

Existing analysis admission retains authentication, idempotency, distributed rate/concurrency
limits, daily quota, force-reanalysis cooldown, and admission lease cleanup. External-call
reservations are deterministic per run/call, so crash retries reuse rather than double-charge them;
terminal completion/cancellation settles them using the existing conservative estimate because
provider adapters do not return billable usage. Core stages continue to use only frozen ports; no
stage reads `process.env`, database globals, provider globals, or direct network APIs. Audit events
record run/stage lifecycle and reuse decisions without copying untrusted document text.
