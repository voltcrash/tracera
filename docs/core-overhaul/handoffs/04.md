## Changed files and behavior

- `packages/ai/src/core/ingestion/acquisition.ts` implements the frozen
  `DocumentAcquisitionPort` plus the image-capable ingestion adapter. Public links use the
  existing `safeFetch` path without changing its SSRF policy. Response bodies are streamed
  to a hard byte bound, redirects remain DNS/IP validated, MIME declarations and image
  signatures are checked, cancellation is propagated, and raw and normalized SHA-256 hashes
  are derived from the retained bytes.
- `packages/ai/src/core/ingestion/html.ts` uses a structured HTML parser to retain title,
  headings, paragraphs, list items, quotations, figure/table captions, image alt text,
  numeric table cells, canonical URLs, language, meta timestamps, exact UTF-16 offsets, and
  stable DOM paths. Short HTTP-200 access, error, CAPTCHA, and anti-bot responses are marked
  blocked rather than treated as articles.
- `packages/ai/src/core/ingestion/normalize-input.ts` implements the frozen
  `NormalizeInputV2` signature for provided text, public links, and images. It writes acquired
  snapshots through the scoped `SnapshotStorePort`, emits start/finish/cancellation audit
  events, and preserves partial, unavailable-capability, and canceled states.
- `packages/ai/src/core/ingestion/types.ts` defines injected OCR, reader fallback,
  reverse-image retrieval, and content-credentials capabilities. It does not widen or modify
  Task 02's frozen `CorePorts`; the document adapter exposes image acquisition as a checked
  optional capability. A reverse-search URL is never generated or reported as a performed
  search.
- `packages/ai/src/core/ingestion/raw-blob-store.ts` adds the local filesystem
  `RawBlobStore` required by the Task 03 handoff. The caller chooses the root; directories and
  files use modes `0700` and `0600`, names are content-derived, writes are immutable, existing
  bytes are verified, traversal and symbolic-link reads are rejected, and stored locators are
  `file:` URLs.
- `packages/ai/src/core/ingestion/index.ts` is the ingestion subpath entry point.
- `packages/ai/test/core-ingestion.test.ts` adds nine deterministic fixtures. The mandated
  blocked-page, misleading-slug, long-text, numeric-table, redirect-rejection, and ambiguous-
  OCR cases all execute. Additional cases cover unsupported MIME, reader-fallback identity and
  hash provenance, and the unavailable-original scoring boundary.

## Contract and API behavior

```ts
const documents = createDocumentAcquisitionPort({
  now: environment.ports.clock.now,
  rawBlobStore: createFilesystemRawBlobStore(worktreeBlobDirectory),
  ocr,
  reverseImage,
  contentCredentials,
});

const result = await documents.acquire({
  url,
  role: "submitted_input",
  maxBytes: 5_000_000,
  signal,
});
```

A failed original is retained only as snapshot identity and discovery context:

```json
{
  "status": "partial",
  "snapshot": {
    "normalizedText": "",
    "extractionStatus": "content_unavailable",
    "extractionMethod": "none",
    "discoveryHints": [{ "kind": "url_slug", "text": "claim shaped slug" }]
  },
  "issues": [{ "code": "content_unavailable" }]
}
```

The slug is never article text or a claim. Because normalization remains non-complete and
the snapshot contains no article text, an unavailable original cannot satisfy the frozen
full-score input condition. Task 11 must pass this input status through unchanged when it
wires orchestration and scoring.

OCR output is limited to visible transcription regions. Each region has a page/frame box and
an explicit `transcriptionUncertain` value. User captions have separate `user_caption`
locators and discovery hints. No person, place, date, visual assertion, authenticity verdict,
or calibrated OCR confidence is inferred. Missing reverse-image or content-credentials
connectors produce `capability_unavailable` issues stating that visual provenance is
unverified and authenticity is not certified. A reader fallback records
`provider@version` in locator paths, lists its limitations in a typed issue, and keeps the
stage partial.

Snapshot persistence still receives tenant, owner, and visibility scope from Task 03's
`SnapshotStorePort`; ingestion adds no database global or cross-owner lookup. Publication
consent is neither inferred nor changed. Network acquisition retains safe-fetch redirect and
DNS rebinding defenses. Cancellation is checked before and throughout fetch, body streaming,
OCR/capability calls, raw-blob persistence, and scoped snapshot persistence. Audit events use
only the run and snapshot identities from `RunEnvironment`.
