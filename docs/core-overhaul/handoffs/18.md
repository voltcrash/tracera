## Behavior/API examples

For a focused report with a null score, the UI displays:

```text
Supported share of resolved claims: Insufficient evidence
Insufficient evidence for a safe score: resolution coverage below threshold
Top claims selected for checking
Evidence unavailable or unresolved for this claim.
```

For cited evidence, the claim card exposes an `Evidence excerpt: “…”` link to the scoped evidence
endpoint and a separate `source link` to the acquired source URL. Screenshot reports show OCR
status and “transcription uncertain” where present; OCR is not presented as image authenticity.
