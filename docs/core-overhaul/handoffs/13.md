```json

```

```

```

Future focused selection applies only after the complete inventory and uses:

```text
duplicateOfClaimId === null
&& coverageDisposition === "factual_claim"
&& checkability === "checkable"
&& material === true
```

The score is calculated only over selected claims with `supported` or `contradicted` verdicts:

```text
100 * supported / (supported + contradicted)
```

For example, two supported and one contradicted selected claims would be `66.666...`; this is
illustrative arithmetic, not a product measurement. The focused report must keep calibration
explicitly unused/null, preserve mixed/unverified/unavailable/partial states, and show the scope
as selected claims only. The current runtime was not changed to emit these focused results yet.
