## Interfaces and examples

`EvaluationAdapter.evaluate(dataset, { mode, split, seed, signal })` returns an adapter run containing adapter/dataset versions and hash, predictions, auditable extraction matches, and outages. Approximate matches use:

```json
{
  "documentId": "doc-1",
  "goldClaimId": "gold-1",
  "predictedClaimId": "claim-7",
  "status": "unresolved",
  "method": "human_review_required",
  "rationale": "Lexical overlap is suggestive but cannot establish semantic equivalence."
}
```

Commands:

```sh
vp run @repo/ai#evaluate:core --mode fixture --split all --seed 20260910
vp run @repo/ai#evaluate:core --mode replay --dataset DATASET --replay RUN --split test --seed 42
vp run @repo/ai#evaluate:core --mode live --dataset DATASET --split development --seed 42
```

Live mode uses the legacy v1 extractor/scorer through the adapter and requires provider credentials. Replay mode requires an adapter-run JSON whose dataset hash matches the selected dataset. No migration or production configuration is required.
